# Welcome to VEN SDK

Welcome to the VEN SDK documentation. Here you will find all the required information to start writing modules for VEN.

## What is VEN SDK?

VEN SDK is a comprehensive development kit for creating League of Legends game modification modules. It provides:

- **Event System** - Hook into game events (attacks, spells, object creation, etc.)
- **Object Manager** - Access to all game objects (champions, minions, turrets, etc.)
- **Rendering System** - Draw 2D and 3D elements on screen
- **Orbwalker Interface** - Advanced attack and movement automation
- **Prediction System** - Skillshot prediction with collision detection
- **Evade System** - Automatic spell dodging
- **Menu System** - Easy-to-use configuration UI
